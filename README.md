# GLIMS

**Greening City Logistics: Innovative Sustainable Last-Mile Solutions**

Simulation framework for evaluating sustainable urban last-mile logistics strategies.

## Overview

GLIMS is a research project focused on developing and evaluating sustainable solutions for urban last-mile logistics. The project investigates how alternative distribution strategies can reduce operational costs, travelled distance, and greenhouse gas emissions while maintaining efficient delivery operations.

This repository contains the simulation framework developed for the first study of the project. It uses real logistics demand data and consolidation centre locations from Barcelona, Madrid, and Valencia to evaluate five last-mile delivery models.

The codebase has evolved from an initial geometric simulator to a road-network implementation based on OSMnx. The intended final architecture is a single simulator that uses real routing information through OSRM. The current OSMnx implementation therefore represents an intermediate stage in that evolution rather than a separate simulator intended for algorithm comparison.

## Features

Current features include:

- Data preprocessing pipeline for transforming raw project datasets into simulation-ready inputs.
- Support for multiple cities and neighbourhoods.
- Evaluation of five urban last-mile logistics models.
- Estimation of travelled distance, operational cost, and CO2 emissions.
- Baseline geometric simulation.
- Road-network routing through OSMnx.
- Command-line interface for selecting cities and neighbourhoods.
- Portable project structure based on shared relative paths.
- Analysis utilities for logistics datasets and simulation outputs.

The preprocessing modules convert the original project datasets into a standardised format. The simulator then applies the selected delivery models to each city and neighbourhood. Results are stored for later inspection and comparison.

```bash
git clone https://github.com/santiagoteor/GLIMS.git
cd GLIMS
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Activate it on Linux or macOS:

```bash
source .venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Usage

### Baseline simulator

The baseline simulator uses geometric distance approximations. It is retained as the original implementation and as a reference while the routing-based simulator is completed.

Run all available cities:

```bash
python -m code.simulation.simulator
```

Run one city:

```bash
python -m code.simulation.simulator --city madrid
```

Run one neighbourhood:

```bash
python -m code.simulation.simulator --city madrid --neighborhood Moratalaz
```

### OSMnx simulator

The OSMnx implementation uses OpenStreetMap road networks to calculate route-based distances. It currently provides the same command-line interface as the baseline simulator.

Run all available cities:

```bash
python -m code.simulation.osmnx_simulator
```

Run one city:

```bash
python -m code.simulation.osmnx_simulator --city madrid
```

Run one neighbourhood:

```bash
python -m code.simulation.osmnx_simulator --city madrid --neighborhood Moratalaz
```

The OSMnx implementation is still under review. Some routing cases may fail when a path cannot be found in the directed road graph. This behaviour is being corrected before the simulator becomes the main implementation.

## Delivery models

The simulation framework evaluates five last-mile logistics models.

| Model | Description |
|-------|-------------|
| M1 | Conventional diesel van delivery. |
| M2 | Electric van delivery. |
| M3 | Consolidation centre to microhub, followed by cargo-bike delivery. |
| M4 | Consolidation centre to a pickup and drop-off point, followed by delivery on foot. |
| M5 | Consolidation centre to a pickup and drop-off point, followed by customer pickup. |

Each model is evaluated using a common demand dataset and a common set of performance indicators.

## Outputs

Simulation outputs are written to the `results/` directory.

Depending on the executed workflow, generated results may include:

- Distance travelled.
- Number of trips.
- Operational cost.
- Estimated CO2 emissions.
- Model-level performance indicators.
- City-level and neighbourhood-level results.

## Simulator evolution

The simulator is being developed incrementally.

```text
Geometric prototype
        |
        v
OSMnx road-network implementation
        |
        v
Single OSRM-based simulator
```

The geometric implementation provided the initial model logic and distance approximations. The OSMnx version introduced routing over real OpenStreetMap road networks. The planned final implementation will consolidate the shared simulation logic into one simulator and use OSRM as the routing engine.

OSRM is not currently implemented in this repository. The transition will be carried out after the OSMnx version has been reviewed and the common simulation responsibilities have been identified.
